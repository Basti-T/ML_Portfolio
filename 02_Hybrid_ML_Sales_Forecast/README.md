## 🧠 Hybrid Intelligence Architecture
The system utilizes a professional-grade **Dual-Model Ensemble** to ensure the forecast is both visionary and realistic:

1.  **Prophet (Strategic Base):** Decodes multi-year seasonality and holiday peaks.
2.  **XGBoost (Tactical Anchor):** Uses a **30-day rolling mean** to tether the forecast to recent performance.
